## JFLAP Assignment Question List

### Topic 12: Regular Grammar to DFA Conversion
1. Convert a Regular Grammar generating strings ending with `'ab'` into a Deterministic Finite Automaton (DFA).
2. Convert a Regular Grammar generating strings starting with `'a'` into a DFA.
3. Convert a Regular Grammar generating strings containing the substring `'aba'` into a DFA.

### Topic 14: Mealy Machine
1. Design a Mealy Machine to calculate the 1's complement of a given binary string.
2. Design a Mealy Machine to print `'E'` for even parity and `'O'` for odd parity of 1s in a binary stream.
3. Design a Mealy Machine to calculate the residue modulo 3 of a binary number.

### Topic 15: Moore Machine
1. Design a Moore Machine to calculate the 1's complement of a given binary string.
2. Design a Moore Machine to calculate the residue modulo 3 of a binary number.
3. Design a Moore Machine to count the number of occurrences of a specific substring (e.g., `'101'`).

### Topic 16: Context-Free Grammar (CFG)
1. Design a Context-Free Grammar for the language $L = \{a^n b^n \mid n \ge 1\}$.
2. Design a Context-Free Grammar for generating palindromes over $\{a,b\}$.
3. Design a Context-Free Grammar for matching balanced parentheses (or arithmetic expressions).

### Topic 17: Pushdown Automata (PDA)
1. Design a Pushdown Automaton for the language $L = \{a^n b^n \mid n \ge 1\}$.
2. Design a Pushdown Automaton for the language $L = \{w c w^R \mid w \in \{a,b\}^*\}$ (Palindrome with center marker).
3. Design a Pushdown Automaton for strings with an equal number of `a`'s and `b`'s.

### Topic 18: NPDA to CFG Conversion
1. Convert a given Non-Deterministic Pushdown Automaton (NPDA) accepting $a^n b^n$ into its equivalent Context-Free Grammar (CFG).
2. Convert a given NPDA accepting palindromes into its equivalent CFG.
3. Convert a given simple state NPDA accepting balanced parentheses into its equivalent CFG.

### Topic 19: CFG to NPDA Conversion
1. Convert the Context-Free Grammar $S \to aSb \mid \lambda$ into an equivalent NPDA.
2. Convert the Context-Free Grammar for palindromes ($S \to aSa \mid bSb \mid c$) into an equivalent NPDA.
3. Convert the Context-Free Grammar for balanced brackets ($S \to [S] \mid SS \mid \lambda$) into an equivalent NPDA.
