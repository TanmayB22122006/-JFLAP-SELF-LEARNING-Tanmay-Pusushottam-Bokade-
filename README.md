JFLAP Assignment Question List
Topic 12: Regular Grammar to DFA Conversion
Convert a Regular Grammar generating strings ending with 'ab' into a Deterministic Finite Automaton (DFA).
Convert a Regular Grammar generating strings starting with 'a' into a DFA.
Convert a Regular Grammar generating strings containing the substring 'aba' into a DFA.
Topic 14: Mealy Machine
Design a Mealy Machine to calculate the 1's complement of a given binary string.
Design a Mealy Machine to print 'E' for even parity and 'O' for odd parity of 1s in a binary stream.
Design a Mealy Machine to calculate the residue modulo 3 of a binary number.
Topic 15: Moore Machine
Design a Moore Machine to calculate the 1's complement of a given binary string.
Design a Moore Machine to calculate the residue modulo 3 of a binary number.
Design a Moore Machine to count the number of occurrences of a specific substring (e.g., '101').
Topic 16: Context-Free Grammar (CFG)
Design a Context-Free Grammar for the language $L = \{a^n b^n \mid n \ge 1\}$.
Design a Context-Free Grammar for generating palindromes over {a,b}.
Design a Context-Free Grammar for matching balanced parentheses (or arithmetic expressions).
Topic 17: Pushdown Automata (PDA)
Design a Pushdown Automaton for the language $L = \{a^n b^n \mid n \ge 1\}$.
Design a Pushdown Automaton for the language $L = \{w c w^R \mid w \in \{a,b\}^*\}$ (Palindrome with center marker).
Design a Pushdown Automaton for strings with an equal number of a's and b's.
Topic 18: NPDA to CFG Conversion
Convert a given Non-Deterministic Pushdown Automaton (NPDA) accepting anbn into its equivalent Context-Free Grammar (CFG).
Convert a given NPDA accepting palindromes into its equivalent CFG.
Convert a given simple state NPDA accepting balanced parentheses into its equivalent CFG.
Topic 19: CFG to NPDA Conversion
Convert the Context-Free Grammar $S \to aSb \mid \lambda$ into an equivalent NPDA.
Convert the Context-Free Grammar for palindromes ($S \to aSa \mid bSb \mid c$) into an equivalent NPDA.
Convert the Context-Free Grammar for balanced brackets ($S \to [S] \mid SS \mid \lambda$) into an equivalent NPDA.
